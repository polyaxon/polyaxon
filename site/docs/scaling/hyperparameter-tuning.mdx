Polyaxon provides several features for running hyperparameter tuning.

## Overview

Oftentimes you may want to create many experiments with different parameters and automatically manage the execution.

## Grid search

Let's run another polyaxonfile `hyperparams_grid.yaml`, which contains a hyperparameter tuning definition with grid search algorithm, this is the content of the file:

```yaml
version: 1.1
kind: operation
matrix:
  kind: grid
  params:
    learning_rate:
      kind: linspace
      value: 0.001:0.1:5
    dropout:
      kind: choice
      value: [0.25, 0.3]
    conv_activation:
      kind: choice
      value: [relu, sigmoid]
    epochs:
      kind: choice
      value: [5, 10]
urlRef: https://raw.githubusercontent.com/polyaxon/polyaxon-quick-start/master/scheduling/experimentation/typed.yaml
```

This is an operation based on the same component used in the previous quick-start guides.
Instead of defining a single set of params, similar to what we did in previous sections of this tutorial,
this file defines a matrix, in this case, with the grid search algorithm.

It uses the same component, Polyaxon validates the search space generated against
the inputs and outputs defined in the component.
It then generates multiple operations based on the search space and manages their execution using a pipeline.

Running an operation with a hyperparameter tuning matrix is similar to any other operation:

```bash
polyaxon run --url https://raw.githubusercontent.com/polyaxon/polyaxon-quick-start/master/scheduling/optimization/hyperparams_grid.yaml
```

If you have cloned the quick-start repo, you can run:

```bash
polyaxon run -f scheduling/optimization/hyperparams_grid.yaml
```

> For more details check the [grid search reference](/docs/references/polyaxonfile/orchestration/matrix/grid-search/).

You can also use the CLI to run this operation without creating a Polyaxonfile:

```bash
polyaxon run --url https://raw.githubusercontent.com/polyaxon/polyaxon-quick-start/master/scheduling/experimentation/typed.yaml -HP learning_rate='linspace:[0.001,0.1,5]' -HP dropout='choice:[0.25, 0.3]' -HP conv_activation='choice:[relu, sigmoid]' -HP epochs='choice:[5, 10]'
```

## Random search

The `hyperparams_random.yaml` polyaxonfile is similar to the grid search polyaxonfile, the only difference is that it defines a random search matrix section:

```yaml
version: 1.1
kind: operation
matrix:
  kind: random
  numRuns: 10
  params:
    learning_rate:
      kind: linspace
      value: 0.001:0.1:5
    dropout:
      kind: choice
      value: [0.25, 0.3]
    conv_activation:
      kind: pchoice
      value: [[relu, 0.1], [sigmoid, 0.8]]
    epochs:
      kind: choice
      value: [5, 10]
urlRef: https://raw.githubusercontent.com/polyaxon/polyaxon-quick-start/master/scheduling/experimentation/typed.yaml
```

To run this polyaxonfile:

```bash
polyaxon run --url https://raw.githubusercontent.com/polyaxon/polyaxon-quick-start/master/scheduling/optimization/hyperparams_random.yaml
```

Random search also provides access to the continuous distributions in addition to the discrete distributions.

> For more details check the [random search reference](/docs/references/polyaxonfile/orchestration/matrix/random-search/).

You can also use the CLI to run this operation without creating a Polyaxonfile:

```bash
polyaxon run --url https://raw.githubusercontent.com/polyaxon/polyaxon-quick-start/master/scheduling/experimentation/typed.yaml --matrix-kind random --matrix-num-runs 10 -HP learning_rate='linspace:[0.001,0.1,5]' -HP dropout='choice:[0.25, 0.3]' -HP conv_activation='pchoice:[[relu, 0.1], [sigmoid, 0.8]]' -HP epochs='choice:[5, 10]' --matrix-concurrency=2
```

## Learn More

Polyaxon provides several generators for defining a [search space](/docs/references/polyaxonfile/orchestration/matrix/params/) and several
[search algorithms for hyperparameter tuning](/docs/references/polyaxonfile/orchestration/matrix/overview/).

You can also learn about tools to [control caching](/docs/references/polyaxonfile/helpers/cache/) of executions with similar configurations,
and [concurrency](/docs/references/polyaxonfile/helpers/concurrency/) for enforcing of parallelism.
Finally, every pipeline in Polyaxon can also define [early stopping strategies](/docs/references/polyaxonfile/helpers/early-stopping/).

The repo contains more hyperparameter tuning examples in the `scheduling/optimization` folder.
