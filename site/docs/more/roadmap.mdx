# Polyaxon Roadmap

Follow what is shipping and what is coming next for machine learning workloads and AI agents on Polyaxon. Explore feature progress below, or visit the [upcoming v3 page](/changelog/v3/v3-0/) for progress and draft release notes.

<Callout type="info" title="Follow the work toward v3">
Features ship incrementally, including in v2. The tracker records each feature's maturity, first shipped version, and available guides. Pending items capture planned work whose maturity and delivery timing are not yet confirmed.
</Callout>

## Shipping and coming next [#feature-progress]
