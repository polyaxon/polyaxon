## Overview

The comparison view is a powerful tool for listing, filtering, sorting, rearranging, and comparing runs.


## Features

Use **Columns** to choose the fields displayed in the run table. You can also rearrange columns and adjust their widths:

![comparison-columns](/images/dashboard/comparison/columns.png)


You can filter and sort by many columns:

![comparison-sort](/images/dashboard/comparison/sort.png)

For runs with logged metrics, open **Layout** and enable **Events** to compare metric and curve charts:

![comparison-scatter](/images/dashboard/comparison/charts-scatter.png)

![comparison-roc-curves](/images/dashboard/comparison/charts-roc-curves.png)

![comparison-lines](/images/dashboard/comparison/charts-lines.png)

![comparison-many](/images/dashboard/comparison/charts-many.png)

![Validation accuracy, learning rate, and validation loss histories across four runs](/images/dashboard/comparison/charts-multi.png)

![comparison-compare](/images/dashboard/comparison/charts-compare.png)

![Bar charts comparing final validation loss and accuracy across four runs](/images/dashboard/comparison/charts-bars.png)

![runs-parallel-coords](/images/dashboard/comparison/dashboards-parallel-coords.png)

Use **Add Widget** in an event section to create a chart or statistics table for the filtered runs:

![comparison-new-charts](/images/dashboard/comparison/charts-new.png)

You can also compare runs with a TensorBoard service when one is available:

![comparison-tensorboard](/images/dashboard/comparison/tensorboard.png)
