## Overview

Open a run's **Files** view to browse its stored artifacts. Download individual files, a subdirectory, or all artifacts for the run. The screenshots use generated documentation files in `acme/demo`.

> The same experience is also possible through the API and the Python client.

![run-artifacts](/images/dashboard/runs/artifacts.png)

## Rendering

Select a text file in **Files** to preview its content.

![run-artifacts-file](/images/dashboard/runs/artifacts-code.png)

The viewer detects programming languages and highlights code.

![run-artifacts-file-dark](/images/dashboard/runs/artifacts-code-dark.png)

## Media

The file viewer also detects and renders supported media formats.

![run-artifacts-audio](/images/dashboard/runs/artifacts-audio.png)

All widgets have a fullscreen mode and the possibility to download the artifact/asset.

![run-artifacts-image](/images/dashboard/runs/artifacts-image.png)
