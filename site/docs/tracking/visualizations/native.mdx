## Overview

Polyaxon dashboard provides several visualizations and charts based on events logged by the [tracking API](/docs/tracking/logging/overview/).

## Single runs [#single-runs]

Open a run's **Dashboards** page to view its logged events. Use **Add Widget** in a section to choose a visualization.

![run-dashboards](/images/dashboard/runs/dashboards.png)

 * Line charts
![run-dashboards-lines](/images/dashboard/runs/dashboards-lines.png)

![run-dashboards-lines](/images/dashboard/runs/dashboards-many.png)

 * Bar charts

![run-dashboards-lines](/images/dashboard/runs/dashboards-bars.png)

 * Stats charts

![run-dashboards-lines](/images/dashboard/runs/dashboards-stats.png)

 * Histogram charts
 * Curve charts: PR curves, AUC/ROC curves, custom curves (`<x, y>` arrays)

Log PR curves with `tracking.log_pr_curve` and ROC curves with `tracking.log_roc_auc_curve`. The native widgets display their average precision and AUC annotations in the legend.

![run-dashboards-pr-curve](/images/dashboard/runs/dashboard-pr-curve.png)

![run-dashboards-roc-curve](/images/dashboard/runs/dashboards-roc-curve.png)

## Media rendering

Polyaxon can render several media types, you can log several versions of the same media with step index:

 * images
 * text
 * html
 * audio
 * video
 * dataframe
