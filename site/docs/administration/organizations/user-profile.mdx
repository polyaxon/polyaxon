Open **Account > Profile** to manage your profile settings, tokens, and bookmarks.

## Profile setting and theme management

You can update your user profile settings as well as your dashboard theme preference.

![light-theme](/images/dashboard/users/light-theme.png)

Polyaxon UI comes in two themes:

![dark-theme](/images/dashboard/users/dark-theme.png)

## Token management

Open **Token** in the profile sidebar to manage API tokens used by the CLI, clients, and external services. The default token remains masked in the example.

![tokens-default](/images/dashboard/users/tokens-default.png)

Each token can be managed, deleted, refreshed, or regenerated:

![tokens-management](/images/dashboard/users/tokens-management.png)

Select **Info Token** to inspect a token's services, scopes, expiration, and timestamps:

![tokens-scope](/images/dashboard/users/tokens-scope.png)


## Bookmarks

Users can bookmark runs and projects for easy access in the future, all bookmarks are located on the user's profile

![user-bookmarks](/images/dashboard/users/bookmarks.png)
