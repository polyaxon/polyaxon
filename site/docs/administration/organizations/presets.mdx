Scheduling presets is a feature for injecting certain information into operations at compilation time to preset configuration for node scheduling,
queue routing, resources requirements and definition, connections, and access level control.

Polyaxon allows to save these presets as Polyaxonfiles, and to use them interactively using Polyaxon CLI. 
Sometimes, some of these presets are generic and can be used in all projects, or you want to configure default 
manifests to be applied to all operations started by a user or in a specific project. 
You can save presets in your organization, and allow users to use them in their Polyaxonfiles.

## Create scheduling presets

If you have admin access, you can create a scheduling preset. The example below requests one GPU, selects T4 nodes with `accelerator: nvidia-tesla-t4`, and routes runs to the `training-cluster/gpu-training` queue.

![Create a GPU preset with a node selector and queue routing](/images/dashboard/presets/create.png)


## Manage scheduling presets

Open **Infra > Presets** to list and manage scheduling presets.

![presets-manage](/images/dashboard/presets/manage.png)

## Presets settings

Select a preset to inspect its **Definition**, project restrictions, and **Settings**. Settings lets you update metadata or delete the preset.

![Settings for the gpu-training-t4 scheduling preset](/images/dashboard/presets/settings.png)

## Presets viewer and usage

Users without admin or owner rights can view the table of available presets in your organization and how they can use them.

![GPU preset definition, node selector, queue routing, and Polyaxonfile and CLI usage](/images/dashboard/presets/usage.png)


## Organization and project default presets [#global-or-per-project-default-preset]

Organization and project administrators can define an ordered list of default presets under **Settings > Defaults**. Move presets from **Available Presets** to **Selected Presets** and arrange them in the order they should apply. Project defaults take precedence over organization defaults.
