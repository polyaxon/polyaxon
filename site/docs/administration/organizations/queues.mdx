Polyaxon provides a queue abstraction to:
  * Prioritize operations on a queue.
  * Throttle the number of operations on a queue.
  * Route operations on a queue to a namespace or cluster.
  * Limit the number of operations queued from a single workflow or nested workflows.


Every agent (compute cluster) comes with a default queue.

## Create queues

Open an agent under **Infra > Agents**, select its **Queues** tab, and choose **New Queue**. Administrators can set the name, description, tags, priority, and concurrency.

![queue-create](/images/dashboard/queues/create.png)

You can also attach a quota to a queue

![queue-create](/images/dashboard/queues/create-quota.png)

> **Note**: The quota field accepts any resource format supported by Kubernetes e.g. (5Gi, 0.5m, 1000, ...)

## Manage queues

You can list, review, and manage all queues for each agent.

![queue-manage](/images/dashboard/queues/manage.png)

You can update or delete a queue.

Open **Infra > Queues** to view available queues across the organization, including their agent, user, priority, and concurrency.
