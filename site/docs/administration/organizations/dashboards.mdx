Dashboards let you create visualizations, render assets, and widgets to analyze a run or a selection of runs.

Oftentimes, a dashboard might be generic and useful to save and reuse for future runs.
Polyaxon lets you save and describe dashboards and share them with the rest of your teams.


## Create dashboards

In a run's **Dashboards** view, add a section and use **Add Widget** to create visualizations. Select the save icon beside the dashboard selector to name the dashboard and set its description, tags, and visibility. The run-level example below uses synthetic data in `acme/demo`.

![dashboard-create](/images/dashboard/dashboards/create.png)


## Select saved dashboards

Open the dashboard selector to find saved dashboards available to the current run or project.

![dashboard-select](/images/dashboard/dashboards/select.png)

## Manage saved dashboards

Select **Manage dashboards** in the selector to review saved dashboards, their owners, and their visibility, or open their action menus.

![dashboard-manage](/images/dashboard/dashboards/manage.png)
