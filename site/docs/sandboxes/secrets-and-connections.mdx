# Secrets and Connections

Sandbox sessions should use the same credential model as the rest of your Polyaxon workloads. Store credentials in Polyaxon connections or Kubernetes-backed secrets, then mount only the connections required by the run.

This page reuses `sandbox/sandbox.yaml` and the `quick-start` project from the [Sandbox Quick Start](/docs/sandboxes/quick-start/). The examples below show the Python client first, followed by the equivalent CLI command.

## Use Connections

Connections are managed by administrators and can represent storage, registries, Git credentials, databases, service accounts, and other external systems. See [connections setup](/docs/setup/connections/overview/) for available connection types.

## Pass Connections to a Run

Add the root `connections` shortcut to `sandbox/sandbox.yaml`, or use a preset that sets it:

```yaml
connections:
  - github-ssh
  - model-storage
```

Initialization handlers under the root `init` shortcut can consume an attached connection when they clone code or download data. Prefer presets for team-wide defaults:

<Tabs items={["Python", "CLI"]}>

<Tab>

```python
from polyaxon.client import RunClient

connection_client = RunClient(project="quick-start")
connection_run = connection_client.create_from_polyaxonfile(
    polyaxonfile="sandbox/sandbox.yaml",
    presets=["dev-connections"],
    approved=True,
)
print(connection_run.uuid)
```

</Tab>

<Tab>

```bash
polyaxon run -p quick-start -f sandbox/sandbox.yaml --presets dev-connections
```

</Tab>
</Tabs>

Both examples start a new service. Python returns its UUID as `connection_run.uuid`; for later CLI commands, replace the current value of `RUN_UUID` with the new run UUID.

## Git over SSH

For private repositories, use an [SSH connection](/docs/setup/connections/ssh/) instead of copying keys into the image or notebook.

## Security Guidance

- Mount only the credentials required by the sandbox.
- Prefer short-lived or scoped credentials.
- Avoid printing secrets in logs or notebooks.
- Stop sandbox runs when access is no longer needed.
- Use [RBAC](/docs/administration/rbac/) and project permissions to control who can start and access sandboxes.

See the Python [run client reference](/docs/references/python-library/run-client/) or the [run CLI reference](/docs/references/cli/run/) for the full interfaces.
