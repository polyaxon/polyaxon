## Overview

By default, Polyaxon operations run without a security context, and pods run as root.
Container-only settings such as `privileged` are not part of the Pod security context, see [Container-only settings](/docs/scheduling/using-k8s-entities/security-context/#container-only-settings).

## Defining a security context preset

If you need to configure a security context for your jobs and services, you can use the [environment.securityContext](/docs/references/polyaxonfile/specification/environment/#securitycontext) section:

```yaml
runPatch:
  environment:
    securityContext:
      runAsUser: 2222
      runAsGroup: 2222
      runAsNonRoot: true
```

By [saving this preset](/docs/administration/organizations/presets/) as `security-context`, users can now use this section in their jobs or services automatically:

```bash
polyaxon run ... --presets=security-context
```

You can also use the preset directly on the component or operation definition:

```yaml
kind: operation
presets: [security-context]
...
```

## Global or per project security context

Organization and project administrators can add a security-context preset to the ordered **Selected Presets** list under **Settings > Defaults**.
