# What is a control plane?

The control plane hosts the software’s business logic and handles insensitive metadata.

It provides a managed API, metadata, scheduling, orchestration, ...

It communicates securely with Polyaxon Agent (compute cluster) and delegates sensitive operations (such as processing, job running, services, resolving secrets, storing or deleting data) to it.
