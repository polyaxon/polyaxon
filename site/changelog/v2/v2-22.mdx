## V2.22.0

### Core

 * **New**: Add composable Python and TypeScript interfaces to specify logic, hardware, and execution through programmatic primitives.
 * **New**: Add reusable replica groups for heterogeneous services.
 * **New**: Allow users to set timezones.
 * **Enhancement**: Polyaxon drops support for Pydantic 1.

### UI

 * **Enhancement**: Move the full-view mode button to the top of the flyout and remove the callout to give back some estate to the main component.
 * **Enhancement**: Improve several UI components.
 * **fix**: PQL button url.

### Traceml

 * **New**: Add optional TPU resource monitoring.
 * **Enhancement**: Improve resources monitoring.
