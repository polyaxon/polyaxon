## V2.21.0

### Core

 * **New**: Add composable Python and TypeScript interfaces to specify logic, hardware, and execution through programmatic primitives.
 * **New**: Allow users to set timezones.
 * **New**: Automatically add name suffixes to hyperparameters children.
 * **New**: Add option to auto-generate run names.

### Traceml

 * **Enhancement**: Improve resources monitoring.
